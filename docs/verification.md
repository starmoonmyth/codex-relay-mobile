# 验证范围

## 1.3.8-rc.2

Windows 与 macOS ARM64 分别运行完整隔离测试，实际数量、构建依赖和源码提交记录在发布附件 `release-manifest.json`。测试使用临时会话、模拟发送和模拟推送，不向日常聊天发送消息。

测试覆盖认证、Origin / Host 校验、重复投递、图片、结构化回复、模型设置、聊天身份与分支隔离、Claude 历史压缩、Grok 原生结束状态、通知去重、通知转发专用认证及跨工作台状态采集。安装包另核对内嵌版本、原生辅助组件、空默认设备列表、Web 资源、许可证及 SHA-256；Mac 包核对 ARM64 架构、ad-hoc 签名与 DMG 完整性。

## 已有实机证据

- Windows Claude Desktop 的隔离聊天已确认原生窗口文字代发、同一聊天记录、回复、模型名称和完成回执。
- Windows 受影响 Claude 压缩记录已确认原回复可见、摘要隐藏、输入框可用，检查前后原始文件未变；该项检查没有发送消息。
- iPhone 用户已确认重建订阅后远程通知可见，也确认 Mac 经 Windows 入口使用原订阅的测试通知可见。

这些证据来自发布前的本地修订。公开包统一使用 1.3.8-rc.2，并重新构建和隔离验证；不将本地编号逐个补发为公开版本。

## 尚未完成

Mac Claude Desktop 辅助功能文字代发尚未完成原生实机验收；Grok 停止状态与 Claude 历史修订仍待真实手机验收。未覆盖所有原生应用版本、分支、连接器和工具审批。统一入口测试通知成功不代表所有工作台的实际任务均完成端到端通知验收。真实 iPhone 键盘布局也未完成实机验证。

该版本保留为预览版，默认稳定下载仍为 1.3.7。具体限制见 [已知问题](../KNOWN_ISSUES.md)。
