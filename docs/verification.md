# 1.3.5 验证范围

Windows 和 Mac Apple Silicon 的当前源码各通过 46 项隔离服务测试，覆盖认证与 Origin / Host 校验、重复投递保护、图片附件、提问回复、桌面 IPC、回执关联、通知状态去重、订阅同步、推送加密，以及 Codex / Claude Code 工作台切换。

模型测试覆盖 Claude 显式模型、模型记录与重试保持，以及 Codex 桌面模型读取、增量修改、读回确认、拒绝和不匹配处理。手机尺寸测试覆盖两种工作台的模型选择、自定义模型 ID、刷新保持与发送核对；本机两端原生模型读取与目录读取另作只读验证。

手机尺寸浏览器测试已覆盖通知组件更新与诊断、键盘视口高度和偏移模拟、历史阅读位置、底部跟随、输入字号，以及提醒合并、数量上限和自动收起。

iPhone 用户已确认本机通知可显示，重建订阅后远程通知也可收到；服务端同时收到了设备接收和系统显示回执。真实 iPhone 键盘布局尚未完成实机验证。

公开安装包从不含预设设备地址的源码重新构建。发行检查不向真实 Codex 聊天投递测试消息，也不修改原始聊天记录。

桌面内部协议存在版本依赖；上述结果不代表所有 Codex 桌面版本都兼容。GitHub Actions 配置用于后续跨平台回归，是否已运行及其结果应以仓库 Actions 页面为准。

Grok 测试覆盖会话过滤、流式片段合并、记录模型、显式完成、模型参数、重复提交、并行任务保护及失败回执。Windows 的隔离原生会话已验证新建后恢复同一会话，连续两轮读取到正确历史和完成状态；没有修改已有工作聊天。手机测试覆盖 Grok 工作台、模型保存与刷新、发送参数，以及不同状态的优先级、颜色、图标、320/390 像素布局和减少动画设置。
