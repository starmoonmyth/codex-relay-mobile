# 验证范围

## 1.3.8 正式版

Windows 与 macOS ARM64 分别通过 130 项隔离测试。实际数量、构建依赖和源码提交记录在发布附件 `release-manifest.json`。测试使用临时会话、模拟发送和模拟推送，不向日常聊天发送测试消息。

覆盖认证、Origin / Host 校验、重复投递、图片、结构化回复、模型设置、聊天身份与分支隔离、Claude 历史与压缩保留链、Grok 原生结束状态、通知去重与转发认证、跨工作台状态采集、更新渠道与公开版本基线、登录启动、配对续期和主动停止。

长任务回归使用超过原读取窗口的 Grok 工具输出，验证处理中、待权限、已中断和已完成状态。真实运行记录与已安装服务接口核对均返回处理中；读取不改写原生文件。

安装包另核对内嵌版本、原生辅助组件、空默认设备列表、Web 资源、许可证及 SHA-256；Mac 包核对 ARM64 架构、ad-hoc 签名与 DMG 完整性。

## 浏览器与服务恢复验证

手机尺寸浏览器已验证长任务状态、中途回复和旧回执不会推断完成、离线不跳配对、自动重连、草稿保留、失效配对提示及离线扫码重试。已有更新检测覆盖静默自动查询、手动查询冷却、网络失败反馈和横向布局。

Windows 与 Mac 的隔离打包服务分别被强制结束，实际在约 56 秒与 30 秒后自动恢复，地址和原配对继续有效；主动停止后保持停止。登录启动注册、后台数据目录固定和本机升级保留通知密钥与订阅均已核对。

## 用户实测验收

用户于 **2026-11-04** 确认 1.3.8-rc.3 的全部待验收问题实测已解决，正式版纳入后续累计修订并关闭待验收记录，包括 Claude Desktop 历史与原生文字代发、Grok 停止和长任务状态、跨工作台及 Mac 统一入口通知，以及手机界面场景。

上述结论区分自动化验证、原生记录核对与用户反馈；不是对所有原生应用版本、连接器或设备的覆盖承诺。功能边界见 [已知问题与接入边界](../KNOWN_ISSUES.md)。
