这个聊天的模型

任务通知

任务完成、失败、中断，或有新问题需要回复时提醒。覆盖这台电脑的聊天。

系统推送可在页面关闭后提醒。iPhone / iPad 需 iOS 16.4 及以上，先添加到主屏幕，再从主屏幕打开并允许通知。Mac 和 Windows 分别开启一次。

电脑需保持开机，且能连接 Apple、Google、Mozilla 或 Microsoft 的推送服务。通知显示聊天标题和任务状态；点击后通过 Tailscale 返回聊天。桌面命令审批仍需在电脑处理。
